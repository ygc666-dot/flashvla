**Abstract— Diffusion-based Vision-Language-Action (VLA) policies have demonstrated strong generalization in robot manipulation, but their deployment can remain unreliable due to spurious visual reliance and stochastic action generation, leading to grounding failures and kinematically unstable behaviors. We introduce Selected Diffusion Noise (SDN), a training-free method that treats diffusion noise as a controllable degree of freedom for improving test-time reliability. SDN samples multiple candidate action chunks and applies two-stage selection: it first filters candidates based on task-relevant visual grounding using a counterfactual negative set, then selects the kinematically most stable chunk based on jerkRMS. Experiments on three VLA policies across both simulation and real-world environments show improvements of 8–10% and 18.33%, respectively, demonstrating SDN’s effectiveness for test-time improvement.**

## I. INTRODUCTION

The emergence of generalist robot policies, such as π<sub>0</sub> [1] and GR00T [2], demonstrates that scaling diffusion-based Vision-Language-Action (VLA) [3], [4] models on large-scale datasets can enable broad multi-task capabilities. However, these policies can remain unreliable during deployment. The stochastic nature of diffusion-based action generation produces multiple candidate action chunks for the same observation and instruction, some of which may exhibit spurious visual reliance or kinematic instability. This raises a practical question: can we improve the reliability of a frozen VLA policy at test time without retraining it? Fine-tuning for task or environmental variations requires additional data and computation, while adapting large-scale VLA models can be costly and risk catastrophic forgetting [5], [6]. These limitations motivate a training-free approach that improves action generation directly at inference time without modifying the underlying policy.

Toward that goal, recent work has begun to exploit the stochasticity of diffusion-based action generation through noise steering [7], [8], [9], [10], best-of-N sampling [11], [12], and non-Gaussian priors [13], [14]. While these approaches improve action selection, two practical challenges remain.

First, VLA policies can rely on task-irrelevant visual cues, leading to spurious grounding and execution failures [15], [16]. For example, in a “place the carrot onto the plate” task, a policy may incorrectly infer a successful grasp and move toward the plate while holding nothing, as illustrated in Figure 2. Second, semantic plausibility does not guarantee physical reliability: a trajectory may reach the intended goal while exhibiting sudden, high-jerk motions that can cause instability and mechanical wear [17], [18].

We address these challenges with Selected Diffusion Noise (SDN), a simple, training-free test-time action selection framework that treats the initial diffusion noise as a controllable degree of freedom. Rather than modifying the denoising process, SDN samples multiple candidate action chunks and selects among them in two stages. It first evaluates visual grounding against a counterfactual negative set generated by masking task-relevant objects to expose spurious correlations, and then selects the most kinematically stable grounded chunk. At each inference step, candidates are generated from both the original and counterfactual observations, where task-relevant objects are masked. These objects are identified in the first frame using an off-the-shelf text-grounded detector (e.g., DINO [19], [20]), and their masks are propagated across frames using a video segmentation model (e.g., SAM-2 [21]).

To further improve execution reliability, we apply kinematic refinement to select the final candidate based on its kinematic stability. This favors chunks with lower jerk and reduces abrupt or oscillatory motions that can lead to unstable execution and mechanical wear [17], [18]. Unlike prior approaches that manipulate model parameters to encourage smoother outputs [22], [10], SDN evaluates the kinematic stability of sampled action chunks directly. This transforms standard stochastic sampling into a lightweight action selection process that can be applied to VLA backbones such as π<sub>0</sub> and GR00T without parameter updates or auxiliary evaluators. Extensive experiments across three VLA backbones (π<sub>0</sub>, GR00T-N1.5/1.6), two simulation benchmarks (Google Robot and WidowX [23]), and two real-world ALOHA tasks demonstrate success-rate improvements of up to 8–10 % in simulation and 18.33 % in real-world tasks, without retraining the underlying policies.

## II. RELATED WORK

## A. Learned Latent Steering.

Recent work has explored steering diffusion latent spaces to adapt pretrained robot policies to new tasks and environments. These approaches include learned adaptation through reinforcement learning for novel scenarios [24], [25] and finetuning for vision-action alignment [26], [27], [28]. Other directions use VLMs as high-level planners or reward providers for low-level diffusion policies [29], [30], [31], or augment policies with retrieval-based memory to leverage global priors and local consistency [13]. Despite their flexibility, these methods typically rely on additional training, environmental rewards, retrieval databases, or external VLMs [24], [26], [13], [31]. Such dependencies limit zero-shot improvement of frozen foundation models at test time. In contrast, SDN is $s e l f -$ contained and training-free, enabling test-time improvement without retraining or relying on external reward evaluators.

## B. Inference-Time Guidance and Policy Selection.

Inference-time guidance and trajectory selection provide alternatives to retraining VLA policies. Classifier-Free Guidance (CFG) [7] steers predictions by contrasting conditional and unconditional fields, while recent best-of-N methods sample multiple candidates and select or aggregate them using external verifiers or ensemble strategies [12]. Policy Contrastive Decoding (PCD) [11] addresses visual grounding by contrasting predictions from original and costly inpainting observations, while BYOVLA [32] repeatedly inpaints irrelevant visual cues to suppress their influence on model attention. ACG [10] instead mitigates jerky motions through designed perturbations of the generation process rather than directly evaluating action smoothness. VLA-Pilot [33] further refines actions through evolutionary optimization with an external reasoning module for reward generation. In contrast, SDN exploits the noise space to generate diverse actionchunk candidates and selects them using two complementary criteria, visual grounding and kinematic stability, enabling training-free improvements in both grounding and execution reliability.

## C. Robustness and Smoothness in Robotic Diffusion.

Robotic diffusion policies can suffer from both unreliable visual features and kinematic instability. DisDP [34] improves robustness by disentangling shared and private modality embeddings to suppress environmental noise, while Colored Gaussian Noise [35] promotes temporally coherent trajectories by modifying the diffusion noise structure. Reactive Diffusion Policy (RDP) [36] combines high-level planning with tactile feedback [36]. These approaches generally require trainingtime modifications or specialized hardware [34], [36]. In contrast, SDN treats kinematic stability as a test-time selection criterion, sampling multiple action chunks and selecting those with lower jerk without retraining or additional hardware.

## III. PRELIMINARIES

We model language-conditioned imitation learning as finding a VLA policy $\pi _ { \theta }$ that maximizes the log-likelihood of expert action chunks $\mathbf { A } _ { t } \in \mathbb { R } ^ { L \times D }$ from a dataset D, where L is the chunk length and D the action dimension. At each timestep $t ,$ the agent receives an observation $\mathbf { o } _ { t }$ consisting of multiple RGB images, the robot’s joint state, and a language instruction ℓ. The VLA architecture comprises a VLM encoder $\Phi ( \cdot )$ that extracts multi-modal context $\mathbf { e }   =   \Phi ( \mathbf { o } _ { t } , \ell )$ and a diffusion transformer $V _ { \theta } ( \cdot )$ that predicts a time-dependent vector field.

Using Flow Matching (FM) [37], [38], the model learns to transport Gaussian noise $\mathbf { A } ^ { 0 } \sim \mathcal { N } ( \mathbf { 0 } , \mathbf { I } )$ to an expert action $\mathbf { A } ^ { 1 }$ via the probability path $\mathbf { A } ^ { \tau } = { \dot { ( 1 - \tau ) } } \mathbf { A } ^ { 0 } + \tau \mathbf { A } ^ { 1 }$ , where $\tau \in [ 0 , 1 ]$ is the flow matching time step. The policy is trained by regressing $V _ { \theta } ( \cdot )$ to the target velocity $\mathbf { \bar { A ^ { 1 } } } - \mathbf { \dot { A } } ^ { 0 } ;$

$$
\mathcal { L } _ { \mathtt { F M } } ( \theta ) = \mathbb { E } _ { \tau , \mathbf { A } ^ { 0 } , \mathbf { A } ^ { 1 } , \mathbf { e } } \left[ \| V _ { \theta } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ) - ( \mathbf { A } ^ { 1 } - \mathbf { A } ^ { 0 } ) \| ^ { 2 } \right] .\tag{1}
$$

We define $\{ \tau _ { k } \} _ { k = 0 } ^ { K }$ as a discretization of the time interval $[ 0 , 1 ]$ , with $\Delta \tau = \tau _ { k + 1 } - \tau _ { k } [ 3 9 ]$ . At inference, actions are generated by solving the ODE $\begin{array} { r } { \frac { d \mathbf { A } ^ { \tau } } { d \tau } = V _ { \theta } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ) } \end{array}$ via the Euler update $\mathbf { A } ^ { \tau _ { k + 1 } } = \mathbf { A } ^ { \tau _ { k } }   +   \Delta \tau   \tilde { V } _ { \theta } ( \mathbf { A } ^ { \tau _ { k } } , \tau _ { k } , \mathbf { e } )$ . This defines a deterministic mapping $f _ { \theta } : \mathbf { A } ^ { 0 } \mapsto \mathbf { A } ^ { 1 }$ , enabling us to treat $\mathbf { A } ^ { 0 }$ as a controllable degree of freedom.

**Classifier-Free Guidance (CFG) [7].** To improve adherence to the instructions, guidance can be applied during ODE integration by modifying the velocity vector field. Let $V _ { \theta } ^ { \mathrm { c o n d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } )$ and $V _ { \theta } ^ { \mathrm { u n c o n d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ^ { \mathrm { u n c o n d } } )$ denote the conditional and unconditional vector fields, where the latter is often obtained by masking the instruction $( i . e .$ $\ell = \emptyset )$ [40]. The guided field is defined as

$$
\begin{aligned} &V _ { \theta } ^ { \mathtt { g u i d e d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ) = \quad V _ { \theta } ^ { \mathtt { c o n d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ) \\&+ w \Big [ V _ { \theta } ^ { \mathtt { c o n d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ) - V _ { \theta } ^ { \mathtt { u n c o n d } } ( \mathbf { A } ^ { \tau } , \tau , \mathbf { e } ^ { \mathtt { u n c o n d } } ) \Big ] ,\\ \end{aligned}\tag{2}
$$

where $w \geq 0$ is the guidance scale. This steers the sampling process toward regions of the action space that are more consistent with the instruction.

## IV. METHODOLOGY

We depict the overall design of SDN in Figure 1a. We first discuss the motivation and then present our two-stage selection algorithm.

## A. Motivation: Two Sources of Action Unreliability

VLA policies can still produce unreliable action trajectories at deployment time. We identify two complementary failure modes. First, policies may rely on spurious visual cues, leading to visual grounding failures such as “ghost-grasping”. Second, they may generate actions that are semantically plausible but physically unstable, exhibiting high-jerk or oscillatory motions. To formalize this intuition, we consider a conceptual decomposition:

$$
\pi _ { \theta } ( \mathbf { A } | \mathbf { o } , \ell ) = ( 1 - \epsilon ) p ^ { * } ( \mathbf { A } | \mathbf { o } , \ell ) + \epsilon p _ { \operatorname { f a i l } } ( \mathbf { A } | \mathbf { o } , \ell ) ,\tag{3}
$$

where $\epsilon \in [ 0 , 1 ]$ denotes the context-dependent probability of unreliable behavior. Here, $p _ { \mathrm { f a i l } }$ captures incorrect or unstable actions arising from approximation errors and spurious correlations. Such behaviors need not be random outliers and may receive non-negligible probability under the same conditioning as expert-like behaviors. Consequently, different initial noise samples can produce substantially different action chunks, motivating inference-time selection of reliable candidates.

**From Local Guidance to Global Selection.** Guidance steers generative models toward desirable outputs [7], [41]. Classifier-Free Guidance (CFG) does so by modifying the conditional velocity field using an unconditional field, which does not explicitly capture structured robotic failures such as spurious-reliance grasps or unstable motions.

A more direct approach would introduce a failure-aware vector field $V _ { \theta } ^ { \mathrm { f a i l } }$ and guide sampling away from it [41], [42], [43]:

$$
V _ { \theta } ^ { \mathrm { g u i d e d } } = V _ { \theta } ^ { \mathrm { c o n d } } + w \big ( V _ { \theta } ^ { \mathrm { c o n d } } - V _ { \theta } ^ { \mathrm { f a i l } } \big ) .\tag{4}
$$

However, failure trajectories are rarely labeled, learning an additional failure model adds overhead [44], and guidance can be sensitive to its scale [45], [46]. Instead, we adopt a global selection perspective: sample multiple action chunks from different initial noises and select select the most suitable candidate, avoiding stepwise intervention during generation.

## B. The Selected Diffusion Noise Framework

We generate multiple candidate action chunks from distinct noise seeds and select the most reliable candidate. This reframes inference as a global search over action predictions rather than step-by-step steering. Our training-free framework performs selection in two stages: it first filters candidates based on visual grounding and then refines them based on physical stability.

**Stage 1: Grounding Filter.** The first stage aims to identify “grounded” initial noise seeds via a contrastive evaluation. Intuitively, we prefer samples that are more consistent with task-aligned behavior while being far from typical failure patterns.

**Constructing selection sets.** At each inference step, we approximate this idea using two sets of action chunk candidates generated from the same policy under different conditions:

• **Positive set (**G**):** Candidates generated from the original observation and instruction, $\widetilde { \mathcal { G } } = \{ \mathbf { A } _ { i } \} _ { i = 1 } ^ { N } \sim \pi _ { \theta } ( \cdot \mid \widetilde { \mathbf { o } } , \ell )$

• **Negative set (**B**):** Candidates generated from a counterfactual observation, $\begin{array} { r } { \mathcal { B } = \{ \mathbf { A } _ { j } \} _ { j = 1 } ^ { N } \sim \pi _ { \theta } ( \cdot \mid \mathbf { o } _ { \mathsf { n e g } } , \ell ) . \; \mathbf { o } _ { \mathsf { n e g } } } \end{array}$ is constructed by perturbing the raw observation to suppress task-relevant visual evidence and induce reliance on spurious cues. We evaluate two perturbations: (1) Inpainting: Removes the target object while preserving the surrounding visual context, (2) Zero bounding-box masking: Removes the target region using zero masking as a simpler and more efficient alternative.

**Contrastive Grounding Score.** A grounded action chunk should remain consistent under the original observation while becoming unlikely under corrupted ones. We formulate grounding as a contrastive, distanced-based ranking problem between a task-aligned distribution $p _ { \mathcal { G } }$ and a failure distribution $p _ { B } .$ Given a candidate action chunk $\mathbf { A } _ { i } ,$ we define its score as the log density ratio $R ( \mathbf { A } _ { i } )   =   \log p _ { \mathcal { G } } ( \mathbf { A } _ { i } )   -$ $\log p _ { \mathcal { B } } ( \mathbf { A } _ { i } )$

Since both densities are unknown, we estimate them from finite samples using k-nearest neighbor (kNN) density estimation [47], [48]. Concretely, let $\overline { { \Omega _ { i } ^ { \mathcal { G } } } }$ and $\Omega _ { i } ^ { B }$ denote the indices of the k nearest neighbors of $\mathbf { A } _ { i }$ in $\mathcal { G } \setminus \{ \mathbf { A } _ { i } \}$ and B, respectively. We define the corresponding local scale estimates:

$$
d _ { \mathcal { G } } ^ { ( i ) } = \frac { 1 } { k } \sum _ { j \in \Omega _ { i } ^ { \mathcal { G } } } \| \mathbf { A } _ { i }   -   \mathbf { A } _ { j } \| _ { 2 } , \qquad d _ { \mathcal { B } } ^ { ( i ) } = \frac { 1 } { k } \sum _ { j \in \Omega _ { i } ^ { \mathcal { B } } } \| \mathbf { A } _ { i }   -   \mathbf { A } _ { j } \| _ { 2 } .\tag{5}
$$

Under standard kNN density estimation, local density is inversely proportional to the neighborhood volume, which is approximated (up to constants) by these average distances [47], [48]. This yields:

$$
\operatorname { l o g } p _ { \mathcal { G } } ( \mathbf { A } _ { i } ) \approx - \operatorname { l o g } d _ { \mathcal { G } } ^ { ( i ) } + C , \quad \operatorname { l o g } p _ { \mathcal { B } } ( \mathbf { A } _ { i } ) \approx - \operatorname { l o g } d _ { \mathcal { B } } ^ { ( i ) } + C .\tag{6}
$$

Substituting into the density-ratio objective gives $R ( \mathbf { A } _ { i } ) \propto$ log $d _ { \mathcal { B } } ^ { ( i ) } - \widetilde { \log d _ { \mathcal { G } } ^ { ( i ) } }$ . For efficiency and robustness, we use a monotonic surrogate that preserves the induced ranking:

$$
R _ { \mathrm { g r o u n d } } ^ { ( i ) } = d _ { \mathcal { B } } ^ { ( i ) } - d _ { \mathcal { G } } ^ { ( i ) } .\tag{7}
$$

If the target object is invisible, the perturbation is disabled and the negative set is empty. The grounding score is then computed solely from the positive set:

$$
R _ { \mathrm { g r o u n d } } ^ { ( i ) } = - d _ { \mathcal { G } } ^ { ( i ) } .\tag{8}
$$

We select the top-M candidates ranked by $R _ { \mathrm { g r o u n d } }$ for kinematic refinement.

**Stage 2: Kinematic Stability Refinement.** To ensure physical feasibility, we further evaluate the remaining M candidates for kinematic reliability. High-jerk or oscillatory motions correspond to abrupt changes in acceleration across consecutive steps, which often lead to unstable or unsafe robot behaviors. To better assess temporal consistency, we generate action chunks that are longer than the executed horizon. These extended action chunks expose delayed oscillations and accumulated instability that may not be observable within short action windows. We quantify smoothness using the JerkRMS metric [49]. For a local candidate action chunk $\mathbf { A } _ { i } ~ = ~ [ a _ { 1 } ^ { ( i ) } , a _ { 2 } ^ { ( i ) } , \widehat { \ldots } , a _ { L } ^ { ( i ) } ]$ , where each $a _ { t } ^ { ( i ) }$ denotes the position-based action at timestep t, we compute:

$$
\begin{aligned} { S ( \mathbf { A } _ { i } ) } & { { } = \sqrt { \frac { 1 } { L - 3 } \sum _ { t = 1 } ^ { L - 3 } \left\| \Delta a _ { t } ^ { ( i ) } \right\| _ { 2 } ^ { 2 } } } \\ { \Delta a _ { t } ^ { ( i ) } } & { { } = a _ { t + 3 } ^ { ( i ) } - 3 a _ { t + 2 } ^ { ( i ) } + 3 a _ { t + 1 } ^ { ( i ) } - a _ { t } ^ { ( i ) } . } \\ \end{aligned}\tag{9}
$$

where

This third-order finite difference captures discrete jerk, and $S ( \mathbf { A } _ { i } )$ corresponds to its RMS magnitude over time. Minimizing $S ( \mathbf { A } _ { i } )$ suppresses candidates that are dynamically unstable, even if they achieve the correct task outcome. We therefore select the final action as:

$$
\mathbf { A } ^ { * } = \arg \operatorname* { m i n } _ { \mathbf { A } _ { i } \in \mathcal { G } _ { M } } S ( \mathbf { A } _ { i } ) .\tag{10}
$$

## V. EXPERIMENTS

## A. Experimental Setup

a) Benchmarks. We evaluate SDN in both simulation and the real world. In simulation, we use SIMPLER [23], following [11] for task selection, with five tasks on the Google Robot and four on the WidowX arm, each evaluated over

50 rollouts. For real-world evaluation, we deploy SDN on ALOHA for two manipulation tasks: placing a cube into a drawer (Cube2Drawer) and placing a banana into a pot (Banana2Pot), each evaluated over 20 rollouts.

b) Baselines. We compare SDN with vanilla VLA policies and five training-free guidance baselines: Classifier-Free Guidance (CFG) $I ^ { 7 }   J ,$ which contrasts conditional and unconditional action fields to strengthen language adherence; Bring Your Own VLA (BYOVLA) [32], which modifies taskirrelevant visual regions to reduce sensitivity to distractors; Action Coherent Guidance (ACG) [10], which disrupts action coherence by replacing attention matrices with identity matrices; White Noise Guidance (WNG), which injects white noise $( \sigma ~ = ~ 1 )$ into action features to disrupt temporal coherence, following its use as a baseline in [10]; and Policy Contrastive Decoding $( P C D ) \left( I I J \right)$ , which contrasts predictions from original and object-masked observations to mitigate spurious visual reliance.

c) Implementation Details. We evaluate SDN on three diffusion-based VLA models: $\pi _ { 0 }$ and GR00T N1.6 in simulation, and GR00T N1.5 in the real world. SDN is training-free and operates only at inference time without modifying the underlying model. For simulation, we use the provided pretrained checkpoints; for real-world experiments, we fine-tune GR00T N1.5 for our robotic platform. All SIMPLER experiments use a single environment instance. We use zero-masking as the primary perturbation to construct the negative set due to its simplicity and efficiency, and evaluate robustness to inpainting in RQ4 (V-E). SDN samples $N   =   1 2$ action chunks from different noise seeds. Stage 1 uses kNN-based contrastive scoring with $k \in \{ 6 , 1 0 \}$ to retain the top- $. M \in \{ 3 , 5 \}$ candidates that are closest to the grounded and farthest from the perturbed action distributions. Stage 2 ranks the remaining candidates using JerkRMS [49] over extended action chunks, with the number of extended chunks searched over {4, 5, 10}. For negative-set construction, we use Grounding-DINO [20] to detect task-relevant objects and SAM2 [21] to track them across timesteps. We then mask their bounding-box regions with zero-valued pixels or inpaint objects with LaMa [50] to remove task-relevant object information.

Such heuristics can push the policy toward out-of-distribution regions, inducing high-frequency oscillations. In contrast, SDN first enforces task-relevant visual grounding through contrastive evaluation against a visually driven negative set and then selects the final action chunk based on kinematic feasibility, yielding smoother motions that are suited for reliable real-world deployment.

## C. RQ2. Why is the negative set useful for Stage 1?

We analyze $\pi _ { 0 }$ and GR00T under masked observations (Table IV). Masking task-relevant objects (Fig. 1b) causes a catastrophic performance collapse: π<sub>0</sub> drops by 61.9% with Masked Object and 62.4% with Inpainting, while GR00T drops by 48.6% and 49.0%, respectively. This degradation reveals reliance on ungrounded visual shortcuts, which we exploit to construct the negative action set for Stage 1.

To rule out masking artifacts, we additionally mask random task-irrelevant regions (Table V). These masks have negligible impact, confirming that the performance collapse is primarily caused by removing task-relevant objects, which forces the models to rely more heavily on background cues. This supports the use of object masking to construct the negative set containing spurious action candidates.

## D. RQ3. Does the grounding mechanism actually select less-spurious actions?

To investigate whether grounding actually selects actions with lower reliance on spurious visual features, we use the Nuisance Mass Ratio (NMR) from VLA-Explain [52], which measures the proportion of prediction-relevant tokens corresponding to irrelevant regions. Higher NMR indicates greater reliance on spurious features. We compare three variants: (1) Base, the original policy; (2) Best Grounding, selecting the candidate with the highest grounding score; and (3) Worst Grounding, selecting the lowest-scoring candidate.

As shown in Table VI, NMR consistently follows the ordering Worst Grounding > Base > Best Grounding across all four tasks. Best Grounding reduces the average NMR from 70.1% to 68%, while Worst Grounding increases it to 75%. This provides empirical evidence that the grounding criterion preferentially selects less-spurious actions, as shown in Fig. 3, and further supports our hypothesis that the negative set captures actions more strongly influenced by spurious visual features.

## VI. DISCUSSION & LIMITATIONS

We have shown that the initial noise in diffusion-based VLAs can serve as a controllable degree of freedom for mitigating spurious visual shortcuts and kinematically unstable motions, with consistent gains across simulation, real-world settings, and diverse backbones. Despite these gains, our perturbations may not cover all failure modes. SDN may suffer from corruption specificity, as object-centric perturbations may miss spurious behaviors caused by dynamic lighting, texture shifts, or broader environmental distractions. Its reliance on fixed hyperparameters may also limit adaptivity to varying task complexity and uncertainty. Future work could explore adaptive candidate allocation and richer multimodal corruption modeling for improved robustness and generalization.

## A. Theoretical Analysis of SDN

We provide theoretical insights into the behavior of the SDN grounding score as the number of samples N increases.

Theorem 6.1: (Asymptotic consistency of SDN contrastive grounding).

Let $p _ { \mathcal { G } }$ and $p _ { B }$ be absolutely continuous densities on a compact support $\Omega   \subset   \mathbb { R } ^ { D }$ , bounded away from zero and infinity. Let $\mathcal { G } _ { N }   =   \{ \mathbf { A } _ { i } \} _ { i = 1 } ^ { N }$ and $\mathcal { B } _ { N }   =   \{ \mathbf { A } _ { j } \} _ { j = 1 } ^ { N }$ be i.i.d. samples from $p _ { \mathcal { G } }$ and $p _ { B }$ , respectively.

For any query $\textbf { A } \in \Omega$ , define the average k-nearestneighbor distances as

$$
d _ { \mathcal { G } } ^ { ( N ) } ( \mathbf { A } ) = \frac { 1 } { k } \sum _ { j \in \Omega _ { k } ^ { \mathcal { G } } ( \mathbf { A } ) } \| \mathbf { A } - \mathbf { A } _ { j } \| _ { 2 } ,\tag{11}
$$

and

$$
d _ { \mathcal { B } } ^ { ( N ) } ( \mathbf { A } ) = \frac { 1 } { k } \sum _ { j \in \Omega _ { k } ^ { \mathcal { B } } ( \mathbf { A } ) } \| \mathbf { A } - \mathbf { A } _ { j } \| _ { 2 } .\tag{12}
$$

The SDN grounding score is defined as

$$
R _ { \mathrm { g r o u n d } } ^ { ( N ) } ( \mathbf { A } ) = d _ { \mathcal { B } } ^ { ( N ) } ( \mathbf { A } ) - d _ { \mathcal { G } } ^ { ( N ) } ( \mathbf { A } ) .\tag{13}
$$

Assume $k \to \infty ,   N \to \infty$ , and $k / N \rightarrow 0$ . Then, for any fixed $\mathbf { A } \in \Omega$

$$
\begin{aligned} { R _ { \operatorname { g r o u n d } } ^ { ( N ) } ( \mathbf { A } ) = C _ { D } \left( \frac { k } { N } \right) ^ { 1 / D } \Big ( } & { { } p _ { \mathcal { B } } ( \mathbf { A } ) ^ { - 1 / D } } \\ { } & { { } - p _ { \mathcal { G } } ( \mathbf { A } ) ^ { - 1 / D } \Big ) ( 1 + o _ { P } ( 1 ) ) , } \\ \end{aligned}\tag{14}
$$

where $C _ { D } = V _ { D } ^ { - 1 / D }$ depends only on the dimension.

In particular, the ranking induced by $\overline { { R _ { \mathrm { g r o u n d } } ^ { ( N ) } ( \mathbf { A } ) } }$ is asymptotically consistent with the population score

$$
R ( \mathbf { A } ) = p _ { \mathcal { B } } ( \mathbf { A } ) ^ { - 1 / D } - p _ { \mathcal { G } } ( \mathbf { A } ) ^ { - 1 / D } .\tag{15}
$$

Proof: From classical k-NN density estimation,

$$
\hat { p } _ { \mathcal { S } _ { N } } ( \mathbf { A } ) = \frac { k } { N V _ { D } \rho _ { k } ( \mathbf { A } ) ^ { D } } \xrightarrow { P } p _ { \mathcal { S } } ( \mathbf { A } ) ,\tag{16}
$$

where $\rho _ { k } ( \mathbf { A } )$ is the k-NN radius.

This implies

$$
\rho _ { k } ( \mathbf { A } ) = \left( \frac { k } { N V _ { D } p _ { \mathcal { S } } ( \mathbf { A } ) } \right) ^ { 1 / D } ( 1 + o _ { P } ( 1 ) ) .\tag{17}
$$

Since the average k-NN distance is asymptotically equivalent to the radius,

$$
d _ { \mathcal { S } } ^ { ( N ) } ( \mathbf { A } ) = \rho _ { k } ( \mathbf { A } ) ( 1 + o _ { P } ( 1 ) ) ,\tag{18}
$$

we obtain

$$
d _ { \mathcal { S } } ^ { ( N ) } ( \mathbf { A } ) = C _ { D } \left( \frac { k } { N } \right) ^ { 1 / D } p _ { \mathcal { S } } ( \mathbf { A } ) ^ { - 1 / D } ( 1 + o _ { P } ( 1 ) ) .\tag{19}
$$

Subtracting the expressions for $\mathcal { B }$ and $\mathcal { G }$ yields the result.
